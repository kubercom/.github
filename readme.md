# Kubernetes Community Podcast · GitHub

Оформление GitHub-организации [kubercom](https://github.com/kubercom).

- [Профиль организации](profile/README.md) — приветственная страница для слушателей и гостей подкаста.
- [Фирменная обложка](assets/podcast-banner.png) — готовый баннер из [брендбука](https://github.com/kubercom/brandbook).

GitHub показывает `profile/README.md` на главной странице организации.
Обложка хранится в этом репозитории; текст профиля можно редактировать отдельно.

Публичный профиль рассказывает о подкасте и темах разговоров. Ссылки на приватные
репозитории, внутренние материалы и личные проекты в него не добавляются.
